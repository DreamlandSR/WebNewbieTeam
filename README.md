# 📚 WebNewbieTeam – E-Learning Web Application

WebNewbieTeam adalah aplikasi **E-Learning berbasis web** yang dikembangkan menggunakan PHP dan MySQL.  
Project ini dibuat sebagai tugas Semester 3 dan bertujuan untuk menyediakan sistem pembelajaran online sederhana dengan fitur login multi-role (Admin, Guru, Siswa).

---

## 🚀 Fitur Utama

- 🔐 Sistem Login & Logout
- 🔑 Reset & Forgot Password
- 👨‍🏫 Dashboard Guru
- 👨‍🎓 Dashboard Siswa
- 🛠 Panel Admin
- 📂 Upload File Materi
- 🗄 Manajemen Database MySQL

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP Native
- **Database:** MySQL
- **Server:** Apache (XAMPP / Laragon)
